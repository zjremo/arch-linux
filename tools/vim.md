# Vim

这里面记录的是Vim一些容易忘记的快捷键。

## shortcuts

```text
1. f快捷键用于在一行中快速找到目标字符，其中f:就是在一行中快速定位到冒号，2f:就是快速找到第二个冒号

2. t和T快捷键与f类似，按下之后输入字符可以移动到目标字符的左侧(t)和右侧(T)一位

3. 回到上一步使用Ctrl+O，回到最新的一步使用Ctrl+I

4. 括号配对: 光标停留在括号上，然后按下%就可以直接转到配对的括号处

5. 替换命令:
- 单行第一个匹配项替换 :s/thee/the <回车> 光标所在行第一个匹配串替换为the
- 替换全行匹配串 :s/thee/the/g 行中所有thee都会被替换为the
- 替换两行之间出现的每个匹配串 :<line_num1>,<line_num2>s/old/new/g 其中前面两个为行号
- 替换整个文件中的每个匹配串 :%s/old/new/g
- 找到整个文件中的每个匹配串，并加上提示是否进行替换 :%s/old/new/gc

6. 快速跳转到某个目录
结合fzf进行搜索，最后进行跳转 -> cd $(fd --type d | fzf)
其实这个后面都是使用的fzf的官方脚本结合bash配置来以快捷键形式来完成
```
